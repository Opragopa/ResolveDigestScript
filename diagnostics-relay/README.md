# Приём журналов без входа пользователей

Этот сервис создаёт Issues только в `Opragopa/ResolveDigestScript`.
Пользователям скрипта аккаунт GitHub не нужен. Администратору требуется
аккаунт Cloudflare и GitHub-токен с правом **Issues: Read and write**
для этого репозитория. Сейчас сервис не развёрнут, `diagnostics.json`
содержит пустой адрес, поэтому журналы остаются локально.

Однократная настройка администратором из этой папки:

```powershell
npx wrangler login
npx wrangler kv namespace create REPORTS
```

Вставьте полученный ID вместо `REPLACE_WITH_KV_NAMESPACE_ID`
в `wrangler.jsonc`. Затем:

```powershell
npx wrangler secret put GITHUB_TOKEN
npx wrangler deploy
```

Команда `secret put` интерактивно запрашивает токен. Не записывайте его
в файлы проекта. В корневом `diagnostics.json` укажите опубликованный адрес:

```json
{"endpoint": "https://resolve-digest-diagnostics.<account>.workers.dev/report"}
```

После публикации этого файла в репозитории клиенты получат адрес при обновлении.
Проверяйте развёртывание на отдельном реальном сбое и убедитесь, что окно
показало ссылку на созданный issue. Автотесты используют заглушки GitHub,
не создают публичные issues и не доказывают настройку токена на сервере.

Приёмник ограничивает размер запроса до 64 КБ, использует Cloudflare Rate
Limiting (3 запроса в минуту на IP и общий ключ), проверяет структуру отчёта
и хранит ID обработанных отчётов в KV семь дней. Rate Limiting и KV распределены:
это ограничение нагрузки и защита от обычных повторов, а не строгая глобальная
квота или гарантия отсутствия дублей при одновременных запросах. При сбое KV
после создания issue или таймауте ответа повтор может создать дубль.

Клиент удаляет имена пользователей из домашних путей, распространённые токены,
параметры URL и данные авторизации URL. В issue попадает диагностический текст,
а не весь накопленный журнал, DOCX или изображения. Произвольные персональные
данные в сообщениях исключений автоматический фильтр может не распознать.

Документация: [секреты Workers](https://developers.cloudflare.com/workers/configuration/secrets/),
[ограничение запросов](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/),
[создание GitHub Issues](https://docs.github.com/en/rest/issues/issues#create-an-issue).
